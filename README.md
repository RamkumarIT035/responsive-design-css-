GlobalMart Supermarket

A responsive supermarket website built using HTML, CSS, and JavaScript. The website is designed to provide a smooth shopping experience on desktop, tablet, and mobile devices.

Features
Responsive design using CSS Media Queries
Mobile-friendly hamburger menu
Home, About, Products, Offers, and Contact sections
Product cards with prices
Add to Cart functionality
Automatic cart quantity calculation
Increase and decrease product quantity
Remove products from cart
Automatic total amount calculation
Checkout functionality
Mobile, tablet, and desktop support
No horizontal scrolling on mobile devices
Technologies Used
HTML5
CSS3
JavaScript
CSS Flexbox
CSS Grid
CSS Media Queries

Shopping Cart Example

If a user adds:

Fresh Tomato × 2 = ₹80
Fresh Milk × 1 = ₹55

The cart automatically calculates:

Total Quantity: 3
Total Amount: ₹135

Users can use the + and − buttons to change quantities.

How to Run
Download or clone the project.
Open the project folder in VS Code.
Make sure these files are present:
index.html
style.css
script.js
Open index.html in Google Chrome.

You can also use the Live Server extension in VS Code.

Testing Responsive Design

Open Chrome DevTools:

F12

Then select:

Toggle Device Toolbar

Test the website using different screen sizes such as:

320px
375px
425px
768px
1024px
